# Advanced Work Board

The Advanced Work Board is a local browser interface for the existing Deep Work Assistant engine. It reads and writes the same local JSONL and SQLite files as the CLI; it does not create a cloud account or duplicate data store.

## Start it on Windows

For the silent daily launch, double-click:

```text
Launch Deep Work Assistant.vbs
```

Use `run_focus_command_center.bat` only when you want a visible troubleshooting console.

Or install and run:

```bash
pip install -e .
deep-work-ui
```

The interface opens at `http://127.0.0.1:8791`. The server binds to localhost by default, so other devices cannot access it unless the host option is deliberately changed. (Port 8791 is deliberately free of the SmartBook control room, which owns 8765 on this machine.)

## Functional surfaces

### Advanced board

- Start and stop persisted Pomodoro cycles.
- Select 25, 50, 90, or 120-minute work sessions.
- Link a focus cycle to a real Kanban card.
- Pause, resume, advance, or stop the timer.
- Start or stop a Deep Work Assistant process using saved launch settings.
- Inspect the adaptive hydration, stretch, and meal schedule.
- Read the actual productivity score, streak, local profile, insights, and 14-day focus trend.
- See the latest local-only posture/activity metrics, posture-reset state, and privacy status in the Vision panel.
- Read the productivity score, effective streak, evidence level, insights, and 14-day focus trend.
- Use `Ctrl+Enter` to start focus and `Ctrl+K` to jump to board search.

### Work Board

- Create, edit, delete, search, filter, and drag cards between valid workflow columns.
- Filter by priority or tag and optionally hide completed cards.
- Store priority, tags, description, application pattern, and window-title pattern.
- Log additional time from the board or card editor.
- Reuse the existing `~/.deep_work_assistant/kanban.db` database.

### Session Intelligence

- Read completed focus sessions from the existing history file.
- Search recent sessions by application.
- Open detailed records containing duration, end reason, reminder outcomes, idle time, and human-versus-agent time when available.
- Export the full session history as JSON.

### Focus Core

- Run actual timed two, five, or ten-minute box-breathing resets.
- Show recommendations generated by the analytics engine.
- Show the real 30-day work-category distribution.

### System configuration and diagnostics

Settings are stored in `~/.deep_work_assistant/ui_settings.json`.

- Persist theme and reduced-motion preferences.
- Configure default focus and break lengths.
- Configure assistant poll interval and reminder response window.
- Enable optional voice reminders and pre-announcement.
- Opt in to privacy-gated local posture vision and set its 30–60 second sampling cadence.
- Set an Obsidian vault path.
- Optionally start the assistant when the UI launches.
- Check Python, Windows capture readiness, optional voice support, data paths, and local record counts.
- Read the output log for the assistant instance launched by the UI.
- Export cards and sessions as exact JSON snapshots.
- Reopen the How It Works tutorial and prepare a local support note from Questions, comments & concerns.

## Visual systems

The same functional interface includes four switchable surface systems:

1. Cinematic Void
2. Afrofuturist Cosmic
3. Liquid Motion
4. AI Core

The ambient canvas responds to the selected visual system. Reduced-motion mode limits particle movement and CSS animation.

## Local files

- Session history: `%LOCALAPPDATA%\DeepWorkAssistant\history.jsonl`
- Kanban database: `~/.deep_work_assistant/kanban.db`
- Pomodoro state: `~/.deep_work_assistant/active_pomodoro.json`
- UI settings: `~/.deep_work_assistant/ui_settings.json`
- UI-managed assistant log: `~/.deep_work_assistant/assistant-ui.log`

## Current boundaries

- The assistant status control knows about the process it launched. It cannot reliably identify a separate assistant process started in another terminal.
- Start Assistant and Begin Focus are separate workflows until the State Truth milestone joins them through one runtime coordinator.
- The interface is a localhost browser application, not a native Windows executable.
- Existing reminder windows and the enforced stretch overlay remain separate Windows UI processes.
- The existing stretch overlay still covers only the primary monitor.
- Windows foreground activity, notifications, and text-to-speech still require verification on Windows hardware.
- Optional posture sensing uses a generic uncalibrated threshold; it does not yet learn a personal posture baseline.
