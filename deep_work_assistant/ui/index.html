PLAIN ANSWERS

Questions, comments & concerns

Why did my timer run without reminders?

Begin Focus is the manual timer. Recovery reminders come from Start Assistant, which runs the Windows activity detector. They are separate today and the interface says so.

Why did a session not appear?

Automatic sessions need stable, human-active Windows use and are saved when the assistant detects a break or shuts down cleanly. Agent-dominated work is labeled separately.

Why did a reminder arrive later than expected?

Recovery clocks advance only during human-active work. Idle and agent-active time pause them.

What triggers the stretch overlay?

Two accepted, consecutive stretch skips trigger a 60-second fullscreen overlay on the primary monitor. A response that does not match an active reminder no longer changes the skip count.

What counts toward a streak?

A completed automatic session needs at least ten minutes of human-active time and must not be agent-dominated. A missed day resets the current streak display.

What information stays local?

Session history, board cards, reminder outcomes, settings, and optional vision metrics stay on this machine. Raw camera frames are discarded. Optional voice uses an online TTS service when enabled.

Does posture sensing learn my body?

No. Optional vision currently uses a generic, uncalibrated threshold after explicit command-line opt-in. Personal posture calibration is a later milestone.
